# ScreenPulse · 屏幕脉搏

Android 屏幕使用时长监控应用（Kotlin，Android UsageStatsManager）。本仓库通过 GitHub Actions 构建 debug APK。

前往 [Actions](https://github.com/zi2111s/apk/actions) 查看 APK 构建记录及下载 `ScreenPulse-debug-APK` 构建产物。

此版本不需要 Root，不读取屏幕图像，不需要联网权限；首次运行需在 Android 系统设置中授予“使用情况访问”权限。当前为测试构建，手机上的统计口径可能与设备厂商数字健康页面不同。
