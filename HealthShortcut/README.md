# 健康使用设备快捷入口 APK

这是独立于 ScreenPulse 的小型 Android 应用。**不尝试自己统计手机用量**，只是打开 vivo / Android 系统已有的“健康使用设备”页面。

* 不需要 Root 或使用情况访问权限。
* 首次打开扫描系统设置中可导出的页面，优先自动直达“健康使用设备”或“使用统计”。
* 如果无法确认页面，可以通过“查找并选择系统入口”测试并记住目标；下次点图标直达。
* vivo 不同系统版本可能不导出目标页面；系统不允许直接打开时，只有“打开设置”兜底。
* 不复制系统 app，不读取其私有数据库，也不宣称能将系统内页面嵌在我们自己的界面。
* 使用专属包名 com.screenpulse.healthshortcut，和原“屏幕脉搏”共存。
